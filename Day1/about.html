About QuickNotes

QuickNotes is a lightweight note-taking app for capturing ideas the moment they occur. It keeps your notes simple, searchable and always within reach.

How to use QuickNotes

  1. Open QuickNotes and click "New note".
  2. Type your idea, reminder or to-do in the note box.
  3. Save the note; it appears instantly in your list.
  4. Search or edit your notes any time.

Features

  • Instant note creation
  • Fast search across all notes
  • Simple, distraction-free layout
  • Keyboard shortcuts for everyday actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
